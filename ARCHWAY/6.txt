# PROMPT 5 — Upgrades / migrations / genesis / params audit

Ты — security research agent для легального bug bounty / responsible disclosure.
Работай только с локальным кодом, локальными тестами, локальной сетью или testnet. Не предлагай эксплуатацию mainnet, DoS публичной сети, кражу средств или действия против чужой инфраструктуры.

Цель: проверить upgrade, migration, genesis, params и module account логику Archway.

Контекст:
В Cosmos SDK сетях серьёзные баги часто появляются не в consensus, а в app-level upgrade/migration logic:
- incorrect migration ordering;
- missing invariant checks;
- invalid genesis accepted;
- unsafe params;
- broad module account permissions;
- export/import mismatch;
- state corruption after upgrade;
- rewards/tracking state not migrated correctly.

Сначала найди файлы и функции по ключам:
`migrations`, `upgrade`, `UpgradeHandler`, `ConsensusVersion`, `Migrate`, `InitGenesis`, `ExportGenesis`, `ValidateGenesis`, `Params`, `SetParams`, `authority`, `gov`, `module account`, `permissions`, `BlockedAddrs`, `invariant`.

Вопросы аудита:

1. Genesis
- Какие invalid states может принять `ValidateGenesis`?
- Проверяются ли duplicate entries?
- Проверяются ли invalid addresses?
- Проверяются ли negative/zero/huge values?
- Согласованы ли module balances и accounting state?
- Что будет при export/import?

2. Migrations
- Все ли старые state keys мигрируются?
- Есть ли ordering dependency между modules?
- Что происходит при partial migration failure?
- Проверяется ли version?
- Есть ли invariant после migration?
- Не теряются ли rewards/tracking/metadata?

3. Params / governance
- Какие params может менять governance?
- Есть ли unsafe ranges?
- Можно ли поставить zero/huge value, ломающее accounting?
- Может ли param change заблокировать claim/distribution?
- Может ли param change создать unexpected windfall?
- Проверяется ли authority?

4. Module accounts
- Какие module accounts есть?
- Какие у них permissions?
- Может ли module account mint/burn/send больше, чем нужно?
- Есть ли blocked addresses?
- Можно ли отправить rewards на module account?
- Согласованы ли bank balances с module accounting?

5. Invariants
- Есть ли invariants?
- Запускаются ли они?
- Покрывают ли rewards/tracking accounting?
- Какие invariants стоит добавить?

Ищи:
- invalid genesis accepted;
- broken export/import;
- migration losing funds/rewards;
- unsafe governance params;
- missing authority check;
- overpowered module account;
- accounting mismatch;
- chain halt after valid governance/migration path;
- panic via malformed state.
